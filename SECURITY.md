# Security Policy

## Supported version

Yalnızca `main` dalındaki en güncel sürüm desteklenir.

## Reporting a vulnerability

Bir güvenlik açığı bulursanız kişisel veri, CV veya örnek saldırı dosyasını
herkese açık issue'ya eklemeyin. Depo sahibine GitHub üzerinden özel bir
güvenlik bildirimi gönderin.

Bildirimde mümkünse şunları paylaşın:

- Etkilenen sürüm veya commit
- Yeniden üretme adımları
- Beklenen ve gerçekleşen davranış
- Kişisel veri içermeyen minimal örnek

Bu proje bir MVP'dir. Güvenilmeyen belge işleme production ortamında ayrı,
kısıtlı bir worker/container içinde çalıştırılmalıdır.
